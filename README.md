## 协作约定

1. 论文事实、项目样本和工作量数据以经确认的原始材料为准。
2. 涉及客户、组织、系统名称及人员信息时，默认匿名化。
3. 对研究问题、分类口径或核心结论的修改，应同步更新 `HANDOFF.md`。
4. 文献引用须记录可核验的出处；不把待验证判断写成既定事实。
5. 开题报告、文献综述和汇报材料分别在对应目录维护，避免多个版本散落在仓库根目录。
